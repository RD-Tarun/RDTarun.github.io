Network Traffic Analysis with Wireshark

Network Analysis November 2024

Introduction

Network traffic analysis is a critical skill for cybersecurity professionals. Whether you're investigating a security incident, troubleshooting network issues, or hunting for threats, understanding how to capture and analyze network packets is essential. In this guide, we'll explore how to use Wireshark, the world's most popular network protocol analyzer, to identify suspicious activities and potential security breaches.

What is Wireshark?

Wireshark is a free, open-source packet analyzer that allows you to capture and interactively browse network traffic. It provides deep inspection of hundreds of protocols and is available for Windows, Linux, macOS, and other platforms.

Getting Started with Wireshark

Installation

Download Wireshark from the official website (wireshark.org) and install it on your system. On Linux, you can typically install it using your package manager: 

sudo apt-get install wireshark  # Debian/Ubuntu
sudo yum install wireshark      # RedHat/CentOS

Basic Capture

To start capturing network traffic:

  1. Launch Wireshark with appropriate privileges
  2. Select the network interface you want to monitor
  3. Click the shark fin icon to start capturing
  4. Perform the network activity you want to analyze
  5. Click the red square to stop capturing

Understanding the Wireshark Interface

Three Main Panes

  • Packet List Pane: Displays all captured packets with summary information
  • Packet Details Pane: Shows protocol hierarchy and details of the selected packet
  • Packet Bytes Pane: Displays raw packet data in hexadecimal and ASCII

Essential Display Filters

Wireshark's display filters are powerful tools for focusing on specific traffic. Here are some essential filters:

Protocol Filters

http           # Show only HTTP traffic
dns            # Show only DNS queries
tcp            # Show only TCP packets
udp            # Show only UDP packets
icmp           # Show only ICMP packets

IP Address Filters

ip.addr == 192.168.1.100              # Traffic to/from specific IP
ip.src == 192.168.1.100               # Traffic from specific IP
ip.dst == 192.168.1.100               # Traffic to specific IP
ip.addr == 192.168.1.0/24             # Traffic to/from subnet

Port Filters

tcp.port == 80                        # HTTP traffic
tcp.port == 443                       # HTTPS traffic
tcp.port == 22                        # SSH traffic
udp.port == 53                        # DNS traffic

Combination Filters

ip.addr == 192.168.1.100 && tcp.port == 80
http && ip.src == 10.0.0.1
tcp.flags.syn == 1 && tcp.flags.ack == 0  # SYN packets

Detecting Suspicious Activities

1. Port Scanning Detection

Look for patterns indicating port scanning:

tcp.flags.syn == 1 && tcp.flags.ack == 0

A single source IP attempting connections to multiple ports on a target system in rapid succession is indicative of port scanning.

2. ARP Spoofing

Detect potential ARP spoofing attacks:

arp.duplicate-address-detected

Multiple MAC addresses claiming the same IP address could indicate an ARP spoofing attack.

3. DNS Tunneling

Identify potential DNS tunneling:

dns && dns.qry.name.len > 50

Unusually long DNS queries or excessive DNS traffic to a single domain may indicate data exfiltration via DNS tunneling.

4. Unusual Protocols or Ports

Filter for uncommon protocols or ports:

!(tcp.port == 80 || tcp.port == 443 || tcp.port == 22)

Traffic on unusual ports should be investigated, especially if originating from internal systems.

Analyzing HTTP Traffic

HTTP traffic analysis can reveal:

Extracting HTTP Objects

  • Navigate to File → Export Objects → HTTP
  • Review downloaded files, images, and scripts
  • Identify potentially malicious downloads

Viewing HTTP Requests and Responses

http.request.method == "GET"
http.request.method == "POST"
http.response.code == 200
http.response.code == 404

Following HTTP Streams

Right-click on a packet and select "Follow → HTTP Stream" to see the complete conversation between client and server.

Advanced Analysis Techniques

1. TCP Stream Analysis

Follow TCP streams to reconstruct entire conversations:

  • Right-click on a TCP packet
  • Select "Follow → TCP Stream"
  • Analyze the complete data exchange

2. Statistical Analysis

Wireshark provides various statistics tools:

  • Protocol Hierarchy: Statistics → Protocol Hierarchy
  • Conversations: Statistics → Conversations
  • Endpoints: Statistics → Endpoints
  • I/O Graphs: Statistics → I/O Graphs

3. Expert Information

Access Analyze → Expert Information to see Wireshark's automated analysis of potential issues:

  • Errors (red)
  • Warnings (yellow)
  • Notes (cyan)
  • Chats (blue)

Real-World Example: Detecting a Malware Infection

Here's a step-by-step approach to analyzing a potential malware infection:

  1. Identify the infected host: Look for systems making unusual outbound connections
  2. Filter traffic: Use ip.src == [infected_host] to focus on traffic from the suspect machine
  3. Check DNS queries: Look for suspicious domains or excessive DNS activity
  4. Analyze HTTP/HTTPS traffic: Identify connections to known malicious IPs or domains
  5. Look for C2 communication: Regular beaconing patterns or encrypted traffic to unusual destinations
  6. Check for data exfiltration: Large outbound transfers or uploads to external sites

Best Practices

  • Capture filters: Use capture filters to reduce file size and focus on relevant traffic
  • Time frames: Limit capture duration to relevant time periods
  • Save captures: Always save important captures for further analysis and evidence
  • Proper authorization: Only capture traffic on networks you're authorized to monitor
  • Privacy considerations: Be aware that packet captures may contain sensitive information
  • Regular practice: Familiarize yourself with normal network patterns to better spot anomalies

Additional Tools

Complement Wireshark with other network analysis tools:

  • tcpdump: Command-line packet analyzer
  • NetworkMiner: Network forensic analysis tool
  • Zeek (formerly Bro): Network security monitoring framework
  • Suricata: IDS/IPS and network security monitoring engine

Conclusion

Network traffic analysis with Wireshark is an invaluable skill for cybersecurity professionals. By understanding how to capture, filter, and analyze network packets, you can detect security incidents, investigate breaches, and gain deep insights into network behavior. Practice regularly with various types of traffic to build your expertise and develop an intuition for spotting anomalies.

Remember that with great power comes great responsibility. Always ensure you have proper authorization before capturing network traffic, and handle captured data with appropriate care to protect privacy and comply with regulations.
